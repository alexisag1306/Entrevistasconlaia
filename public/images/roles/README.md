- `web.webp` — Alicia Christin Gerald, [Developer typing code on a laptop screen](https://unsplash.com/photos/developer-typing-code-on-a-laptop-screen-xaWYIbNIOdw)
- `backend.webp` — Taylor Vick, [Server room with network cabinets](https://unsplash.com/photos/server-room-with-network-cabinets-aWslrFhs1w4)
- `database.webp` — Stephen Dawson, [Turned on monitoring screen](https://unsplash.com/photos/turned-on-monitoring-screen-qwtCeJ5cLYs)
